## Windows Setup (PowerShell)

### 1. Create and activate the virtual environment (Python 3.12)

# Create the virtual environment (first time only)
py -3.12 -m venv .venv

# Activate it
.\.venv\Scripts\Activate.ps1

# If PowerShell blocks activation, run:
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1


### 2. Install Python dependencies (first time only)

pip install -r requirements.txt


### 3. Generate the synthetic dataset
# (Skip if data\out\ksp.db already exists)

python data\generator\generate.py --cases 40000 --seed 42
python data\build_sqlite.py


### 4. Train all models
# (Skip if already trained)

cd backend\ml
python cli.py train-all
cd ..\..


### 5. Start the API
# Open a new PowerShell window (Terminal A)

.\.venv\Scripts\Activate.ps1
cd backend\appsail_ml
python -m uvicorn app:app --port 8000

API Documentation:
http://127.0.0.1:8000/docs


### 6. Start the Dashboard
# Open another PowerShell window (Terminal B)

cd frontend

# First time only
npm install

# Start the development server
npm run dev

Dashboard:
http://localhost:5173
